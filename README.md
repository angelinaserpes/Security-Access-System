# Secure Access & Threat Monitoring System 🔐

A Java-based cybersecurity application implementing **role-based access control (RBAC)** with authentication and a full audit logging system.

## Features

- **Role-Based Access Control** — granular permissions per user role (Admin, Manager, User)
- **Authentication system** — secure login with credential validation
- **Audit logging** — every access attempt and permission change is recorded with timestamps
- **Threat monitoring** — flags suspicious activity patterns

## Stack

| | |
|---|---|
| Language | Java |
| Paradigm | OOP — SOLID principles |
| Security | RBAC, authentication, audit trails |

## Run locally

Compile and run with any Java IDE (IntelliJ, Eclipse) or from the command line:

```bash
javac src/*.java
java -cp src Main
```
